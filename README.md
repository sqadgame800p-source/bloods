# ДЕЛО В МЯСЕ — сайт компании

Простой сайт на HTML + CSS + JavaScript. Меньше абстракций, больше сути.

## Как открыть

Сайт открывать **не двойным кликом по файлам, а через запуск мини-сервера** —
так она ведёт себя как настоящий сайт (это нужно и для корзины, и для будущей оплаты):

1. В папке с сайтом дважды щёлкни `СТАРТ-САЙТА.sh` (если спросит — «Запустить»).
   Откроется сайт по адресу `http://localhost:8000`.
2. Всё! Сервер будет работать, пока сайт открыт.
3. Закончил работу — запусти `СТОП-САЙТА.sh`.

⚠️ Если открыть страницы просто двойным кликом по файлам (по адресам `file://...`),
в Firefox корзина может «разделяться» между страницами — это особенность браузера.
Всегда запускай через `СТАРТ-САЙТА.sh`.

├── delivery.html     — доставка
├── order.html        — оформление заказа + отслеживание статуса
├── branches.html     — филиалы со ссылками в 2ГИС

├── contacts.html     — контакты

│   └── style.css     — все стили: анимации, адаптив (телефон / планшет / ПК)
├── js/
│   ├── data.js       — ДАННЫЕ: блюда, филиалы, этапы заказа
│   ├── main.js       — ЛОГИКА: меню, фильтры, анимации, лого
│   ├── cart.js       — КОРЗИНА: хранится в localStorage

│   ├── background.png — фон-фото в хуке (затемнение настраивается в variables.css)
│   └── logo.jpg       — лого в шапке (подхватывается автоматически)
└── README.md         — этот файл

## Логотип

1. Сохрани логотип из Instagram (правая кнопка → «Сохранить картинку»).
2. Назови файл `logo.jpg` и положи в папку `img/` (уже сделано).
3. Сайт сам покажет лого вместо текстового названия в шапке.

## Карточки блюд

У карточки сверху есть место под фото. Пропиши в `js/data.js` путь в поле `img`,
например:

```js
{ name: "Новая шаурма", price: 300, category: "Шаурма",
  img: "img/dishes/shaurma-big.jpg", emoji: "🌯", description: "..." },
```

- Фото положи в папку `img/dishes/` (выше по формуле: `img/dishes/имя.jpg`).
- Если фото пока нет — карточка покажет тёмную заглушку с эмодзи (`emoji`), выглядеть будет нормально.

## Карта 2ГИС на главной

Виджет карты подключён в `js/data.js` (блок `gisMap`). Чтобы карта заработала,
нужен **ID организации** из 2ГИС:

1. Открой 2gis.ru → найди компанию «ДЕЛО В МЯСЕ» в своём городе.
2. В адресной строке браузера увидишь ссылку вида `.../70000001021786250/`
   — это число и есть `orgId`.
3. Из ссылки же возьми английское название города (например `novosibirsk`)
   и запиши в `city`.
4. Заполни в `data.js`: `orgId`, `city`, `lat` (широту) и `lon` (долготу) —
   координаты видны в ссылках 2ГИС (два числа через запятую)
   или попроси ИИ-помощника вставить всё по ссылке на компанию.

Пока `orgId` пустой — на главной вместо карты показывается аккуратная
заглушка, а кнопка «Открыть в 2ГИС» (поиск по названию) работает всегда.

## Как работает заказ (демо)

1. На страницах меню кнопка «В корзину» — корзина копится в localStorage.
2. На `order.html`: имя, телефон, доставка/самовывоз, адрес, комментарий курьеру, выбор оплаты.
3. После оформления — отслеживание: «Принят → Готовится → Почти готово → Курьер в пути → Доставлен».
4. Пока этапы «двигаются» сами по таймеру (симуляция). Когда появится сервер и система — этапы будут приходить из API, корзину и данные заказа заменит настоящая база.
